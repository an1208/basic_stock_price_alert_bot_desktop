# Basic Stock Price Alert Bot for Desktop
Never miss a dip or a breakout again. 📈 This Python-powered sentinel monitors live market data 24/7 and delivers instant desktop alerts the second your target price hits. Built with yfinance and automated logic to turn market volatility into opportunity.

✨ Features
Real-Time Monitoring: Fetches live market prices using the Yahoo Finance API.

Instant Notifications: Desktop pop-ups via plyer so you don't have to keep a browser tab open.

Custom Thresholds: Easily set "Buy" or "Sell" targets for any ticker (Stocks, Crypto, ETFs).

Resource Efficient: Low-footprint background process with customizable check intervals (default: 10 mins).
